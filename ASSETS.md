# Assets

Every 3D model in this game is original and generated by `scripts/build-assets.ts` in this repository. There are no
downloaded or third-party models, textures or sounds.

| file | what | made by |
|---|---|---|
| `public/models/bunkers.glb` | one inflatable-style bunker per shape in the field layout | `scripts/build-assets.ts` |
| `public/models/marker.glb` | the first-person marker | `scripts/build-assets.ts` |
| `public/models/player.glb` | the player figure, with idle / run / crouch / crouchMove / shoot / out animations | `scripts/build-assets.ts` |
| sound effects | synthesised at runtime | `src/audio.ts` |
| turf texture, paint splats | drawn at runtime on a canvas | `src/world.ts`, `src/fx.ts` |

Rebuild the models with `npm run assets`. CI fails if the committed files don't match the script.

If you add third-party assets, list each one here with its source, author and license, and only use licenses that allow
redistribution (for example CC0 or CC-BY with credit).
